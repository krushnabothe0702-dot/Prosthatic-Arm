# Robotic Hand Prototype — Documentation

A small GitHub Pages-ready site documenting the prototype shown in the supplied photos.

## Publish with GitHub Pages

1. Create a GitHub repository for this project and add the files in this folder, keeping the `images` folder beside `index.html`.
2. In the repository, open **Settings → Pages**.
3. Under the build and deployment settings, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub will show the published site address in the Pages settings after deployment finishes.

The photo notes stick to visible details. Add verified information about the design, assembly, controls, and testing when you have it.
